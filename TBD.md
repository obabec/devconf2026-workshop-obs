Tempo metrics generator remote_write pointing to a wrong URL. The metrics generator runs fine, processes all traces, generates service graph and span metrics internally — but silently fails to write them to Mimir because the endpoint is wrong. Symptoms:

Traces arrive and are fully queryable
Alloy shows zero errors (not Alloy's problem)
Mimir has no traces_service_graph_* or traces_spanmetrics_* series
Service graph in Grafana is completely empty
No obvious error anywhere unless you look at Tempo's own logs or metrics
The diagnosis path is non-trivial:

Traces work → rule out Alloy
Service graph empty → could be Grafana config, Tempo config, or Mimir
Check Mimir for traces_* metrics → none → issue is upstream of Mimir
Realise service graph data is generated by Tempo's metrics generator, not Alloy
Check Tempo metrics generator config → find the remote_write URL → spot it's wrong
Fix the URL
